# MVP - Controle de Livros

## Objetivo

Controlar livros lidos e pendentes.

## Funcionalidades

- Criar Livro
- Listar Livros
- Atualizar Status
- Excluir Livro
- Sugestão de Próxima Leitura

## Arquitetura

Controller
↓
Service
↓
Repository
↓
LocalStorage

## Uso de IA

A IA foi utilizada para:

- Gerar arquitetura
- Gerar CRUD
- Criar testes
- Criar documentação

## Como Executar

Abrir:

index.html

no navegador.
